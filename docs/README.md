## 문서 규칙

- **결정에는 이유를 붙인다.** "이렇게 한다"만 적으면 반년 뒤에 왜 그랬는지 몰라 뒤집었다가
  같은 사고를 되풀이한다. 실측 숫자가 있으면 숫자로 남긴다.
- **하지 않기로 한 것도 적는다.** 기각된 안이 더 좋아 보이는 날이 반드시 온다.
- 날짜는 절대 날짜로. "어제 고침" 은 다음 주에 읽으면 아무 뜻이 없다.

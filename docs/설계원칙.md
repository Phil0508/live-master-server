# 설계 원칙

이 시스템 전체를 관통하는 규칙. 새 기능은 여기서 벗어나지 않게 만든다 —
벗어났던 자리마다 방송 사고가 났고, 그 사고들이 이 규칙을 만들었다.

## 1. 서버가 유일한 진실이다

주사위 눈, 황금열쇠 뽑기, 카드 섞기 — **무작위와 판정은 전부 서버가 정한다.**
화면(오버레이·조종실·폰)은 결과를 연출로 옮겨 그릴 뿐이다.

- 화면에서 정하면 오버레이 두 개가 서로 다른 결과를 보여준다.
- 새로고침하면 결과가 사라진다.
- 시청자가 "조작 아니냐"고 물을 때 답이 없다.

**연출 신호는 `action {type, ts, …}` 방식.** 서버가 신호에 타임스탬프를 실어 보내면,
화면은 "새 신호인가(ts가 본 것과 다른가) + 아직 신선한가(몇 초 안인가)"로 연출 여부를
정한다. 늦게 합류한 창은 연출 없이 마지막 상태로 선다. (시그뒤집기·주사위게임이 이 방식)

## 2. 상태에는 주인이 있다

조종실이 스위치 하나를 눌러도 상태 전체가 POST 된다. 그 사본은 몇 초 전 것이라,
그 사이 서버가 바꾼 값을 덮어쓴다. 실제 사고: "시그니처가 씹힌다", 동시 배정 25건 중 17건 소실.

- **`SERVER_OWNED`** — 상태 전체 POST 가 와도 서버 값을 유지하는 필드.
  큐·대기함·시그게임·주사위게임·집계 두 개(sig_tally/donor_tally).
- **`PATCH_DENY`** — 설정 패치(`/api/settings/patch`)로 못 바꾸는 필드.
  점수·로그·큐·집계는 전용 엔드포인트로만 바뀐다.
- **새 서버 소유 상태를 만들면 두 목록에 먼저 등록하고 시작한다.**

## 3. 점수는 델타로만 움직인다

`/api/score/add` 에 "더할 값"을 보낸다. 상태 전체에 점수를 실어 보내면 낡은 사본이
남의 점수를 되돌린다. 같은 이유로:

- 배정은 `pending_id` 를 함께 보낸다 — 서버가 "점수 지급 + 대기함 제거"를 한 잠금에서
  처리하고, **대기함에 없으면 이미 처리된 것**이므로 점수를 더하지 않는다(`already: true`).
  폰과 PC가 같은 후원을 동시에 눌러도 두 번 안 들어간다.
- 나눠주기 합계는 혼자 받았을 때와 같아야 한다. 계산식은 `splitPoints()` 하나뿐이고
  조종실과 폰에 같은 사본이 있다(한쪽만 고치면 갈라진다 — 검사가 글자 단위로 비교한다).
- 자동으로 점수가 움직이는 길은 함부로 넓히지 않는다. 주사위 점수 칸도
  "누구 차례인지 골랐을 때만" 자동이다.

## 4. 인증은 기본이 잠금이다

`before_request` 가 모든 경로를 잠그고, 예외 목록(`exempt_routes`)에 있는 것만 연다.
**새 API 는 아무것도 안 하면 잠긴다** — 열 때만 의식적으로 결정한다.
OBS 브라우저 소스는 세션이 없으므로 방송 화면류(GET)만 예외다.
무인증으로 나가는 상태는 `state_for_client` 한 군데를 반드시 거친다
(덮인 카드 정체·황금열쇠 덱·대기 후원·장부를 거기서 지운다).

## 5. AI 는 보조일 뿐, 방송을 멈출 수 없다

- AI 는 추천·요약만 한다. **점수를 직접 바꾸지 않는다.**
- AI 가 죽으면 배정은 대기함에 남는다 — 안전한 쪽으로 실패한다.
- 모델 이름은 환경변수(`NIM_MODEL` 등)다. 2026-08-26 에 쓰던 모델 둘이 같은 날
  서비스 종료(410)돼 방송 중에 멈췄다 — 코드에 박혀 있으면 방송 중에 못 고친다.
- 붐빔(429/5xx)은 예비 모델로 자동 전환. 410/401 은 다시 해도 같으므로 그대로 알린다.
- nemotron 계열은 추론(생각)을 끈다(`NIM_NO_THINK`). 켜면 생각으로 토큰을 다 쓰고
  답이 잘리며, 그 생각이 화면에 그대로 샌 사고가 있다.

## 6. 파일에는 함정이 있다 (수정 전 필독)

| 파일 | 줄끝 | 주의 |
|---|---|---|
| server.py, controller.html, admin.html | CRLF | 문자열 패치 시 `\r\n` 으로 |
| overlay.html | LF + **NUL 2바이트** | **반드시 바이트로 읽고 쓰기**, NUL 개수 보존 확인 |
| mobile.html | LF | |

- **Bash heredoc 은 백슬래시를 먹는다.** `\n` 이 진짜 줄바꿈이 돼 파일이 깨진 사고가
  여러 번 있었다. 패치 스크립트는 파일(Write)로 만들어 실행한다.
- 파이썬 `round()` 는 5를 짝수로 보내고 JS `Math.round()` 는 올린다. 화면 코드를
  검사할 때 파이썬으로 옮겨 적으면 4만5천·5만원에서 거짓 통과가 난다 —
  **파일에서 꺼낸 진짜 JS 를 node 로 돌려라.**

## 7. 검증 없이는 끝난 게 아니다

고치면 [검증체계.md](검증체계.md)의 전체 검사를 돌리고, 새 기능에는 전용 검사를 만들어
러너에 등록한다. 원칙: 검사는 "그렇게 짜여 있는가"(정적)보다 "실제로 그렇게 되는가"(실행)를
본다. 다시 갈라지면 안 되는 것(나눠주기 식 등)은 정적 검사로 못을 박는다.

# 🎲 주사위게임

부루마블처럼 테두리를 도는 판에서 말을 움직이는 방송용 게임. 2026-08-27 도입.

## 확정된 규칙 (사장님 결정)

| 항목 | 결정 | 이유 |
|---|---|---|
| 굴리기 | **진행자 버튼** (조종실·폰) | 멘트 치고 나서 굴린다. 후원 연동은 나중에 얹기 쉽다 |
| 말 | **공용 1개** | 판이 단순하고 화면이 깔끔하다. 구조는 여러 개 담게 짜여 있다 |
| 주사위 | **하나가 두 번 구른다** | 두 개 동시보다 그림이 낫다. `5 + 4 = 9` 로 합계가 쌓인다 |
| 도착 효과 | 칸이 가운데 크게 떴다가 저절로 사라짐 | 시그니처는 재생, 미션·열쇠는 표시 후 소멸, 점수는 자동(조건부) |
| 판 크기 | 기본 7×5(20칸), 4×3~10×8 | 실제로는 작게 쓴다 — 30칸짜리는 안 한다 |

## 칸 종류

- **🏁 출발** (0번 고정) — 지나면 바퀴 수 +1, 🎉 배너
- **📜 미션** — 적어둔 글이 크게 떴다가 사라짐
- **🎵 시그니처** — 그 시그니처가 기존 재생 경로로 재생. **재생 정보는 칸을 편집할 때
  미리 받아 둔다** (굴리는 순간 Supabase 에 물으면 잠금 안에서 네트워크를 기다려
  후원 접수가 멈춘다). 재생 전용이라 시그니처 순위 집계에는 안 센다
- **💯 점수 (±1000 한도)** — "누구 차례"를 골라뒀을 때만 자동 반영.
  기여도·로그·기여도순 정렬·대결 팀 합산까지 기존 점수 규칙의 축소판
  (`_dicegame_apply_score`). 안 골랐으면 표시만 하고 안내를 남긴다
- **🔑 황금열쇠** — 덱(최대 40장)에서 **서버가** 한 장 뽑는다. 화면마다 다른 카드가
  나오면 안 되므로 뽑힌 카드를 action 에 실어 보낸다. **덱은 무인증에 감춘다**
  (뽑기 전까지 비밀, 장수만 표시용으로 나간다)

## 서버 구조

`state['dicegame']` = `{enabled, cols, rows, dice(굴림 횟수 1~2), pos, laps, tiles[], keys[], action{}}`

API (전부 로그인 필요): `setup`(같은 번호 칸 내용 보존) · `tile` · `keys` · `roll` ·
`move`(비상 손잡이) · `enable` · `reset`(칸·덱은 남긴다)

- SERVER_OWNED + PATCH_DENY 등록 — 상태 전체 POST 에 안 덮인다
- 연타 방지: 앞 연출 길이(굴림 횟수×1.3초 + 칸당 0.3초 + 여유)만큼 429.
  `move` 는 action 을 바꾸므로 연타 잠금을 푸는 뒷문이기도 하다(의도된 것 — 검사도 쓴다)
- setup 은 "안 보낸 값"(기본)과 "보냈는데 숫자 아님"(400)을 구분한다

## 연출 시간표 (overlay)

```
0        굴림 시작 (3D 정육면체, 시작 방향·바퀴 수만 무작위 — 멈추는 눈은 서버 값)
k×1300   k번째 굴림 시작, +930 에 멈추고 합계 갱신
rollT    = 250 + 굴림수×1300 부터 말이 칸당 300ms 총총
rollT+경로×300+120   도착: 칸 강조 + 금빛 파열 링 + 카드 공개(미션·열쇠 5초, 빈칸 2.2초)
```

판 배경은 **투명**이다(2026-08-27) — 초록 펠트를 쓰다 걷었다. 방송 화면 위에 칸만 뜨는 편이
깔끔하고, 어떤 장면 위에도 얹힌다. 대신 배경으로 가려주지 못하므로 칸·주사위 각각의
그림자를 진하게 해서(0.75~0.8) 밝은 영상 위에서도 윤곽이 살게 했다.

3D 주사위: 면 배치는 실제 주사위(맞은편 합 7). 회전각에 360° 배수를 더해 굴리므로
몇 바퀴를 돌든 멈추는 면은 정확하다. 점은 CSS — 사진·글꼴 불필요, OBS 그대로.
칸: 밝은 면 + 두꺼운 아랫단(입체 블록), 종류별 색, rotateX(13°) 기울임,
말은 대기 중 둥실거림. 리액션 모드가 켜지면 판이 같이 숨는다.

## 앞으로 할 만한 것 (하기로 한 건 아님)

- **후원 연동 굴림** — 정한 금액 이상 후원이 오면 자동으로 한 번. 서버 굴림이라 얹기 쉽다
- **플레이어별 말** — tiles/pos 구조는 이미 여러 말을 담을 수 있게 여지를 둠. 차례 관리가 관건
- **말 꾸미기** — 지금은 🐴 이모지. 플레이어 사진으로 교체
- 황금열쇠에 점수·이동 효과 붙이기 (지금은 글만)

- ~~점수 칸 무조건 자동~~ — 자동으로 점수가 움직이는 길을 넓히지 않는다 (설계원칙 3)

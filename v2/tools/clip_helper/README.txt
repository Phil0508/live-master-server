쇼츠 클립 도우미 — 회사 컴퓨터(OBS 있는 곳)용

1. 이 폴더를 아무 데나 풀어 두세요 (예: 바탕화면).
2. start_clip_helper.bat 을 더블클릭하세요.
   - 처음 한 번은 폴더 두 개를 고르는 창이 떠요.
     ① OBS 녹화 폴더 (OBS 설정 → 출력 → 녹화 경로와 같은 곳)
     ② 쇼츠 클립을 모을 폴더
3. 방송하는 동안 까만 창을 켜 두세요. 클립이 저장될 때마다
   "✂ 옮김: 2026-10-01 21-14-50 밍밍 1,000,000원 VIP.mp4" 처럼 떠요.
4. 폴더를 바꾸고 싶으면 change_folders.bat 을 더블클릭하세요.

파일 이름 규칙과 클립마다의 제목은 조종실(v2) → 탭 줄의 [✂️ 클립] 에서 바꿔요.
이 도우미에는 서버 주소와 '목록 읽기 열쇠' 가 들어 있어요. 서버를 옮기거나 열쇠를 새로 만들면
조종실에서 도우미를 다시 받아 주세요(창에 "서버에 못 붙어요 (401)" 이 뜨면 이 경우예요).
제목을 고치면 이미 옮긴 파일 이름도 몇 초 안에 따라 바뀝니다.

OBS 에서 처음 한 번만:
  - 설정 → 출력 → 리플레이 버퍼 → "리플레이 버퍼 사용" 체크, 최대 시간 180초
    (클립은 누른 순간 앞 90초 + 뒤 90초 — 방송판이 90초 뒤에 저장한다. 90초로 두면 뒤 90초만 남는다)
  - 방송판 브라우저 소스 → 페이지 권한 → "OBS에 대한 고급 접근 권한" (방송판 한 곳에만)
  - 리플레이 파일 이름은 OBS 기본("Replay ...")으로 두세요. 도우미가 이 이름으로 찾아요.

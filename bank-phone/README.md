# 📱 엔젤 입금알림 (안드로이드) — 0.1

공기계(안드로이드)에서 **기업은행 앱 두 개**(i-ONE Bank · IBK 스마트알림)의 입금 알림을 읽어
방송 서버 **후원 콘솔 → 🏦 계좌 입금 추천** 칸으로 보내는 앱입니다. 은행 웹 확장과 같은 칸에 '· 폰'으로 떠요.

- **송출하지 않습니다.** 카드가 뜨면 후원 콘솔에서 [채우기] → 보고 고쳐서 [시그니처 송출].
- 기업은행 앱 두 개의 알림**만** 읽어요. 다른 앱 알림(카톡 등)은 보지도 않아요.
- 보내는 곳은 방송 서버(엔젤컴퍼니.메인.한국) 한 곳뿐입니다(시험용으로 집 안 공유기 주소만 더 허용).
- 보내는 것: 입금 금액 · 시각 · 알림에 적힌 보낸 사람(통장 표시). 알림 원문은 **폰 안에만** 남아요.
- 인터넷이 끊기면 폰에 모아 뒀다가 30초마다 다시 보내요. 30초마다 '살아 있음' 신호도 보내요.

## 폰 준비 (처음 한 번)

1. 공기계에 **기업은행 i-ONE Bank**(와 IBK 스마트알림)를 깔고 로그인 → 입출금 알림 켜기
2. 이 앱 파일(`엔젤입금알림-0.1.apk`)을 폰으로 옮겨 열기 → "출처를 알 수 없는 앱 허용" → 설치
3. 앱을 열고
   - **① 알림 읽기 권한 켜러 가기** → 목록에서 '엔젤 입금알림' 켜기
   - **배터리 절약에서 빼러 가기** → 허용
   - **② 열쇠**: 후원 콘솔 → 🏦 계좌 입금 추천 → [은행 확장 연결] → [복사] 한 열쇠를 붙여 넣고 **저장**
     (카톡 '나에게 보내기' 등으로 폰에 옮기면 편해요. 열쇠는 32글자)
   - "✓ 방송 서버로 보냄"이 뜨면 연결 끝
4. **③ 시험 알림 보내기** → 후원 콘솔에 '시험손님 1,000원' 카드가 뜨면 성공 (카드는 [숨기기])
5. 폰은 **충전기에 꽂아** 두세요(배터리 절약 모드가 알림을 늦출 수 있어요)

## 진짜 입금으로 시험

다른 통장에서 기업은행 계좌로 1,000원을 두 번(메모 있게 한 번 · 없이 한 번) 보내고,
앱 화면 **④ 최근 기업은행 알림**을 캡처해 보내 주세요. 알림 문구에 맞춰 읽는 규칙을 다듬어요.
"입금 알림인데 못 읽은 것 n건"이 뜨면 꼭 캡처해 주세요.

## 만드는 사람용

```bash
python bank-phone/build_apk.py      # → D:/android-dev/out/엔젤입금알림-<판>.apk
```
- 도구는 D 드라이브(`D:/android-dev`)에: 자바 17(Adoptium) · 안드로이드 SDK(platform 34 · build-tools 34.0.0)
- 서명 열쇠는 `D:/android-dev/keys` — **지우면 다음 판을 덮어 깔 수 없어요**(지우고 새로 깔아야 함). 저장소에 안 올려요.
- 알림 읽기 규칙 검사: `src/.../Parser.java` + `test/ParserTest.java` (컴퓨터 자바로 돎 — `tests/bankphone_parser_test.py`)

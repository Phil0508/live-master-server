# 🏦 엔젤 입금확인 (기업은행) — 0.4

**0.4 (10-16)** — 상자가 '신호등 바'로 바뀌었어요. 왼쪽 점이 초록(조회 중) · 노랑(주의) · 빨강(끊김 — 바 전체가 빨개져요).
바를 누르면 예전 내용(단추 · 찾은 입금 · 기록 · 열쇠)이 펼쳐져요. 새 입금은 바 위로 초록 말풍선이 떠요.
조종실 **⚙ 설정 → 시스템 → 은행 확장** 칸에 같은 바가 거울처럼 뜨고, 거기서 **자동 조회 켜기/끄기 · 간격 · 지금 조회 · 기준 다시 잡기**를 누르면
확장이 다음 신호 때(25초 안) 따라 해요. 은행 **로그인**만은 이 PC에서 직접 해야 해요.

기업은행 **거래내역조회** 화면에서 [조회]를 30초마다 대신 눌러 주고, 새로 들어온 **입금**만 골라
방송 서버 **후원 콘솔 → 🏦 계좌 입금 추천** 칸으로 보내는 크롬 확장 프로그램입니다.

- **송출은 하지 않습니다.** 후원 콘솔에 카드가 뜨면 [채우기] → 닉네임 · 메시지를 보고 고쳐서 → [시그니처 송출].
  배정(누구 ＋)은 지금처럼 대기함에서 합니다. 카드의 '밍밍 ＋? 예상' 은 참고만.
- 로그인은 대표님이 직접 합니다. 이 프로그램은 비밀번호 · 이체 화면을 건드리지 않습니다.
- 누르는 것은 [조회] 하나, 읽는 것은 거래내역 표 하나뿐입니다.
- 보내는 곳은 **방송 서버(엔젤컴퍼니.메인.한국)** 한 곳뿐입니다(시험용으로 내 PC 127.0.0.1 도 허용).
  보내는 내용: 입금 금액 · 시각 · 거래내용/예금주 칸. 잔액 · 출금은 보내지 않습니다.
- [조회]를 누를 때마다 기업은행 로그인 12분이 다시 시작돼서, 켜 두는 동안 로그인이 유지됩니다.

## 설치 (처음 한 번, 2분)

1. 크롬 주소창에 `chrome://extensions` 를 치고 엔터
2. 오른쪽 위 **개발자 모드** 스위치를 켭니다
3. 왼쪽 위 **압축해제된 확장 프로그램 로드** → 이 폴더 선택
   `바탕화면\AngelCompany\excel-broadcast\bank-watch`
4. 목록에 "엔젤 입금확인 (기업은행)" 이 보이면 끝
   (0.1 을 깔아 두셨으면 목록에서 **새로고침(↻)** 만 누르면 0.2 가 됩니다)

## 방송 서버와 잇기 (처음 한 번)

⚠️ 방송 서버에 이 기능이 올라간 뒤에 됩니다("올려" 하신 뒤).

1. 후원 콘솔 → **🏦 계좌 입금 추천** 칸 오른쪽 **[은행 확장 연결]** → 열쇠 **[복사]**
2. 기업은행 거래내역조회 화면의 상자 맨 아래 **방송 서버 연결** 을 펼쳐 열쇠 붙여 넣기 → **[저장]**
3. 상자 두 번째 줄이 **"방송 서버로 보냄 ✓"** 이 되고, 후원 콘솔에 **"은행 확장 연결됨 · n초 전"** 이 뜨면 끝

## 시험하는 법

1. 크롬에서 기업은행 개인 인터넷뱅킹에 **로그인**
2. **조회 → 거래내역조회** 로 가서 기간을 넉넉히(예: 1주일), 정렬은 **최근순**, [조회] 한 번
3. 오른쪽 아래 상자에 "표를 찾았어요" 가 뜨면 **[자동 조회 켜기]**
4. 그대로 두고 **1~2시간** 지켜보기 (다른 일 하셔도 됩니다 — 그 탭만 닫지 마세요)
5. 중간에 다른 통장에서 기업은행 계좌로 **1,000원** 두 번 보내 보기
   - 한 번은 받는 분 통장 표시(메모)를 `테스트 안녕` 으로
   - 한 번은 메모 없이
6. 상자 "새 입금" 에 두 건, 후원 콘솔 추천 칸에 카드 두 장이 뜨면 성공

## 보내 주실 것

상자만 캡처해서 보내 주세요(계좌 내역 표는 안 찍으셔도 됩니다).
상자에는 이런 것이 적혀 있어요:
- 찾은 칸 이름(입금칸 · 잔액칸 · 날짜칸 · 이름/내용칸) — **메모가 어느 칸에 찍히는지** 이걸로 봅니다
- 켜 둔 시간 · 조회 횟수 · 마지막 정상 시각 — **로그인이 몇 시간 유지되는지** 이걸로 봅니다
- 새 입금 목록 · 기록(은행 알림창이 떴다면 그 내용)

## 상자에 이런 말이 뜨면

| 상자 문구 | 뜻 · 할 일 |
|---|---|
| 거래내역 표를 못 찾았어요 | 거래내역조회 화면에서 [조회]를 한 번 눌러 주세요. 그래도 그러면 상자를 캡처해 보내 주세요 |
| 조회 버튼을 못 찾았어요 | 상자의 **[버튼 지정]** → 은행 화면의 [조회]를 한 번 누르면 기억합니다 |
| 오래된 거래가 위에 있어요 | 정렬을 **최근순** 으로 바꿔 주세요 |
| 조회 기간 날짜 칸을 못 찾았어요 | 자정 넘어 입금이 안 보일 수 있어요. 상자를 캡처해 보내 주세요 |
| 로그아웃된 것 같아요 | 다시 로그인하고 거래내역조회 화면으로 가면, 그사이 들어온 입금도 다음 조회 때 잡힙니다 |
| 열쇠를 넣어야 방송 서버로 보내요 | 위 **방송 서버와 잇기** 를 해 주세요. 그 전까지 찾은 입금은 상자에만 있고, 이으면 같이 보내요 |
| 열쇠가 맞지 않아요 | 후원 콘솔에서 [새 열쇠]를 만들었으면, 새 열쇠를 다시 붙여 넣어 주세요 |
| 방송 서버에 연결하지 못했어요 | 인터넷 · 서버 문제예요. 찾은 입금은 확장에 쌓아 두고 30초마다 다시 보냅니다 |

- 완전히 지우려면 `chrome://extensions` 에서 이 확장의 **삭제**

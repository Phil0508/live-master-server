# 🤖 진행봇

방송에서 일어난 일을 유튜브 라이브 채팅에 알려주는 프로그램입니다.

```
방송 서버 ──SSE(/api/stream)──> 진행봇 ──> 유튜브 라이브 채팅
```

- **방송 서버(`server.py`)는 하나도 안 건드립니다.** 봇은 방송판과 똑같이 그냥 손님으로 붙습니다.
  봇이 죽어도 방송은 멀쩡하고, 방송 중에 봇만 껐다 켤 수 있습니다.
- **AI 안 씁니다.** 할 말이 전부 서버가 아는 사실이라 문구표 빈칸에 끼워 넣으면 됩니다.
- **새로 깔 것 없습니다.** 파이썬 표준 라이브러리만 씁니다.

---

## 무엇을 알리나

봇은 **말수가 적습니다.** 화면에 이미 떠 있는 것을 채팅이 또 읽어주면 시끄럽기만 합니다.
지금 치는 건 이 넷뿐입니다.

| | 언제 | 보기 |
|---|---|---|
| 💝 후원 감사 | **리액션이 화면에 나올 때** | `💝 구름이님 50,000원 후원 감사합니다! 🙏` |
| 👑 1위 바뀜 | 순위 1등이 바뀌면 | `👑 하늘별님이 1위로 올라섰습니다!` |
| 💛 계좌 안내 | 7분마다 (조용할 때) | `후원 계좌 기업은행 464-… (엔젤컴퍼니) · 보내주시면 바로 화면에 올려드립니다!` |
| 💬 질문 | 90초 넘게 아무 일도 없으면 | `오늘 누가 1등 할 것 같아요?` |

> 💝 후원 인사에 **누가 얼마** 후원했는지가 들어갑니다. 후원할 때마다 이름이 채팅에 뜨는 게
> 후원하는 맛입니다.
>
> ⏳ **도착할 때가 아니라 리액션이 화면에 나올 때 인사합니다.** 후원은 도착과 동시에 리액션
> 큐에 들어가지만, 앞에 밀린 게 있으면 화면에 나오기까지 한참입니다. 그 사이에 채팅이 먼저
> '누가 얼마' 를 말하면 연출을 다 까먹습니다(스포).
> 리액션이 안 걸리는 소액 후원은 깔 스포가 없으니 **도착하자마자** 인사합니다.
>
> ⚠️ 오버레이가 꺼져 있으면 리액션이 영영 안 나옵니다. 그래서 `reaction_wait_max_sec`
> (기본 600초)을 넘기면 **그냥 먼저 인사합니다.** 늦은 인사가 없는 인사보다 낫습니다.
> 봇을 껐다 켜면 기다리던 후원은 인사가 빠집니다 — 그건 기억이 봇 안에만 있기 때문입니다.
>
> ⚠️ **조종실에서 선수에게 점수를 배정하는 건 한 건씩 알리지 않습니다.** 후원 인사에 이미
> 후원자 이름이 있고, 배정은 조종실 사정입니다. 한 후원에 두 줄이 나가면 시끄럽습니다.

**계좌 안내가 이 봇의 핵심입니다.** 방송 중간에 들어온 분은 후원하는 법을 모릅니다.
화면에는 떠 있지만 폰으로 보면 작고 **복사가 안 됩니다.** 채팅에 있으면 길게 눌러 복사됩니다.

### 🔇 일부러 안 치는 것들

**지운 게 아니라 옮겨 놨습니다.** 알아보는 코드는 그대로 있고 문구만 비웠습니다.

| | 왜 껐나 | 어떻게 되돌리나 |
|---|---|---|
| 🎲 주사위 전부 (굴림·점수·한 바퀴·황금열쇠·뺏기·블랙홀) | 화면에 판이 보이는데 채팅이 굴림마다 따라 읽으면 시끄럽습니다 | `messages.json` 의 `_꺼둔_문구` 에서 같은 이름 칸에 옮겨 붙이기 |
| 🎯 목표 진행 (`50% 왔습니다`) · 달성 | 화면 게이지가 이미 보여줍니다 | 〃 |
| 🔥 접전 (`단 20,000 차이!`) | 점수차 얘기를 안 하기로 했습니다 | 〃 |
| 📊 순위 요약 | 〃 | `config.json` → `notices.rank_every_sec` 를 `480` 으로 |
| 🏺 모금함 | 〃 | `config.json` → `notices.fundjar_every_sec` 를 `600` 으로 |

> 👑 1위 바뀜은 남겼지만 **"예지랑님과 30,000 차" 부분은 뺐습니다.** 순위가 바뀐 건
> 점수차 얘기가 아니라서요. 이것까지 빼시려면 `messages.json` 의 `rank_top` 칸을 `[]` 로 비우면 됩니다.
> 점수차를 다시 붙이시려면 `_꺼둔_문구` 의 `rank_top(점수차 있는 것)` 을 옮겨 붙이세요.

> 💡 **코드는 그대로 다 있습니다.** 끄고 켜는 건 전부 `messages.json` 과 `config.json`
> 두 파일뿐이라, 방송 중에도 봇만 껐다 켜면 바뀝니다.
>
> ⚠️ 방송 서버(`server.py`)의 주사위게임은 **아무것도 안 건드렸습니다.** 게임은 그대로
> 돌아가고 화면에도 그대로 나옵니다 — **봇이 그걸 채팅으로 안 읽어줄 뿐입니다.**

## 1단계 · 입 막고 돌려보기 (유튜브 필요 없음)

```bash
python bot/announce.py
```

유튜브에 **아무것도 안 칩니다.** "이 시각에 이렇게 쳤을 것이다" 를 화면과 `bot/dryrun.log` 에만 남깁니다.

방송 한 회차 이렇게 돌려보시고 **말수가 적당한지, 문장이 어색하지 않은지** 봐주세요.
말이 많으면 `config.json` 의 `min_interval_sec` 를 늘리거나, `messages.json` 에서 그 칸을 비우면 됩니다.

연결만 확인하려면:

```bash
python bot/announce.py --once
```

### 서버 주소·로그인

`config.json` 의 `server` 를 방송 서버 주소로 맞춰주세요. 같은 컴퓨터면 그대로 두면 됩니다.

`logs`(룰렛 결과 같은 것)는 **로그인해야 보입니다.** 환경변수로 넣어주세요:

```bash
set ADMIN_PASSWORD=조종실비밀번호
```

안 넣어도 돌아갑니다 — 후원·주사위·순위·목표는 로그인 없이도 옵니다.

### 미리 하실 것

**① 봇 계정 만들기**
`엔젤컴퍼니 진행봇` 처럼 **봇인 게 이름에 보이게** 만들어주세요. 사람인 척하면 유튜브 정책에
걸리고, 시청자를 속이는 것도 됩니다. 멤버 전용 채팅이면 봇 계정도 멤버여야 합니다.

**② 구글 클라우드에서 API 켜기**
1. <https://console.cloud.google.com> → 프로젝트 만들기
2. `YouTube Data API v3` 사용 설정
3. **OAuth 동의 화면** → 외부 → 앱 이름·이메일만 채우고 저장
4. ⏳ **그 화면에서 `프로덕션으로 게시` 를 꼭 누르세요** (아래 경고 참고)
5. 사용자 인증 정보 → **OAuth 클라이언트 ID** → **데스크톱 앱** →
   `클라이언트 ID` · `클라이언트 보안 비밀` 받기

> ### ⏳ `테스트` 상태로 두면 **7일마다 봇이 멈춥니다**
>
> 구글 규칙입니다 — 동의 화면이 `테스트` 면 갱신 토큰이 **7일 만에 만료**됩니다.
> 그러면 봇이 아무 말 없이 조용해지고, 일주일 뒤라 원인을 짐작하기도 어렵습니다.
> **`프로덕션으로 게시`** 를 누르면 안 만료됩니다.
>
> 게시할 때 "확인되지 않은 앱" 이라고 뜨는데 **그대로 두셔도 됩니다.** 사장님 계정
> 하나만 쓰는 앱이라 구글 심사를 받을 필요가 없습니다. 연동할 때 경고가 한 번 뜨면
> `고급` → `(앱 이름)(으)로 이동` 을 누르시면 됩니다.

**③ 계정 연동 — 명령 한 줄**

```bash
python bot/link.py
```

②에서 받은 **클라이언트 ID·보안 비밀**을 물어보면 붙여넣으세요. 브라우저가 열립니다.

> ⚠️ **반드시 봇 계정으로 로그인하세요.** 본계정으로 하면 본계정 이름으로 채팅이 올라갑니다.
> 제일 흔한 실수라, 연동이 끝나면 **어느 채널에 묶였는지 이름을 찍어서** 보여줍니다.
> 틀렸으면 그냥 다시 돌리면 됩니다.

허용을 누르면 `bot/token.json` 이 자동으로 만들어집니다. **한 번만 하면 됩니다.**

나중에 확인하고 싶으면:

```bash
python bot/link.py --check      # 지금 어느 계정에 묶여 있나
```

⚠️ `token.json` 은 `.gitignore` 에 들어 있어 저장소에 안 올라갑니다.
**남에게 보내지 마세요** — 이 파일만 있으면 봇 계정으로 글을 쓸 수 있습니다.
환경변수(`YT_CLIENT_ID` · `YT_CLIENT_SECRET` · `YT_REFRESH_TOKEN`)를 써도 됩니다.

### 어느 채팅방에 치나

아무것도 안 적으면 **지금 켜져 있는 내 라이브를 자동으로 찾습니다.** 방송마다 주소를
붙여넣지 않아도 됩니다. 특정 방송에 고정하려면 `config.json` 의 `youtube.video_id` 에
영상 id 를 적으세요.

## 말수 조절

| 설정 | 뜻 |
|---|---|
| `min_interval_sec` | 최소 몇 초에 하나. 늘리면 조용해집니다 (기본 25) |
| `idle_after_sec` | 이만큼 조용하면 질문을 던집니다 (기본 90) |
| `daily_budget` | 하루 최대 개수. 넘으면 **후원 감사만** 남깁니다 (기본 180) |
| `only_when_broadcasting` | 방송이 꺼져 있으면 아무 말도 안 합니다 |
| `notices.*_every_sec` | 되풀이 안내 간격. **`0` 이면 끕니다** |
| `notices.gap_sec` | 안내끼리의 최소 간격 (기본 120) |
| `notices.close_gap` | 1·2위 격차가 이 밑으로 오면 **접전**이라고 외칩니다 (기본 50,000) |

밀린 소식이 6건을 넘으면 **낮은 것부터 버립니다.** 30초 지난 소식을 뒤늦게 치면 더 이상합니다.
유튜브가 "너무 빠르다" 고 막으면 **스스로 간격을 두 배로** 늘립니다.

> ⚠️ 유튜브 하루 한도(10,000단위)에서 채팅 한 줄이 몇 단위인지는 **문서에 안 적혀 있습니다.**
> 쓰기 작업 통례대로 50이면 하루 200개입니다. 2단계를 켠 뒤 구글 클라우드 콘솔의
> 할당량 화면에서 실제로 얼마나 쓰는지 보고 `daily_budget` 을 맞춰주세요.

## 문구 고치기

`bot/messages.json` 하나만 고치면 됩니다. 코드는 안 건드려도 됩니다.

- 한 칸에 문구를 여러 개 두면 **돌아가며** 씁니다 (같은 말이 연달아 나오면 봇 티가 납니다)
- **칸을 `[]` 로 비우면 그 사건은 아예 안 칩니다**
- `{중괄호}` 는 서버 값으로 채워집니다. 없는 이름을 쓰면 그 문구만 조용히 건너뜁니다 (안 죽습니다)
